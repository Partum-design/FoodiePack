# FoodiePack

Plataforma responsive para una dark kitchen orientada a oficinas. Permite consultar el menú por día, apartar comidas, armar un paquete semanal con descuento, simular el pago, consultar pedidos y administrar la oferta diaria.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run build
```

La experiencia es mobile-first y deja preparada la base visual para convertirse en PWA o envolverse más adelante con Capacitor para Android. Los datos del prototipo se conservan en `localStorage`; el pago es una simulación y no realiza cargos reales.
